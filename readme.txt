Extension légère pour afficher des avis clients dans WordPress.

== Description ==

Version 0.1.0 :

* socle de l’extension ;
* page Réglages > Avis Google ;
* stockage dans une option unique ;
* shortcode temporaire [gd6d_reviews] ;
* architecture prête pour l’API Google Places et le cache.

== Installation ==

1. Téléverser le fichier ZIP dans Extensions > Ajouter une extension.
2. Activer Gd6d Reviews.
3. Ouvrir Réglages > Avis Google.
4. Renseigner le Place ID et, plus tard, la clé API.
