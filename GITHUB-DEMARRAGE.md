# Démarrage GitHub Desktop

## 1. Créer le dépôt

Sur GitHub, créer un dépôt privé nommé `gd6d-reviews`.

Ne pas ajouter de README, de licence ou de `.gitignore` au moment de la création : les fichiers existent déjà dans le projet.

## 2. Installer GitHub Desktop

Installer GitHub Desktop, puis se connecter avec le compte GitHub.

## 3. Ajouter le projet local

1. Décompresser `gd6d-reviews.zip`.
2. Dans GitHub Desktop : **File > Add Local Repository**.
3. Sélectionner le dossier `gd6d-reviews`.
4. Si GitHub Desktop propose de créer un dépôt dans ce dossier, accepter.

## 4. Premier commit

Dans le champ **Summary**, écrire :

`Création du socle de l’extension`

Cliquer sur **Commit to main**.

## 5. Publier sur GitHub

Cliquer sur **Publish repository**.

Vérifier :

- Name : `gd6d-reviews`
- Keep this code private : coché
- Organization : aucune, sauf besoin particulier

Puis cliquer sur **Publish Repository**.

## Les trois boutons à retenir

- **Commit to main** : crée un point de sauvegarde local.
- **Push origin** : envoie les commits sur GitHub.
- **History** : affiche l’historique et permet de retrouver une ancienne version.

## Routine pour les prochains sprints

1. Remplacer ou modifier les fichiers du dossier local.
2. Vérifier la liste des changements dans GitHub Desktop.
3. Écrire un résumé clair.
4. Cliquer sur **Commit to main**.
5. Cliquer sur **Push origin**.
